# FPS: Добивания и Зомби (Three.js Shooter)

## Описание проекта
Шутер от первого лица в ретро/комиксной стилистике на Three.js и Vite.
В игре присутствуют следующие враги:
- **Zombie** — базовый враг ближнего боя с поведением окружения недосягаемого игрока
- **Mutant** — крупный брут с прыжковой атакой (leap) и ударом по земле (slam)
- **Robot** — парящий противник дальнего боя с моделью призрака (`ghost.glb`), лазерными залпами и защитой от кемперства
- **StrawReaper** — пугало с серпом (`reaper.glb`), высокий опасный рукопашный противник со скелетными анимациями, смертоносным рывком (charge) с замахом и телеграфной полосой, окном уязвимости (recovery, 1.5x урон), неподвижной засадой (ambush), поведением кольца при недосягаемом игроке и сопротивлением стаггеру

> **ВАЖНО**: Солдат (`Soldier`, `Cover`) в игре нет и не планируется. Все упоминания удалены из кодовой базы.

## Архитектура
- `src/core/` — игровой цикл (`Game.js`), ввод (`Input.js`), физика коллизий (`Physics.js`), кеш 3D-моделей и клонирование анимаций (`ModelCache.js`), ГПСЧ (`Rng.js`), пулы объектов (`Pool.js`)
- `src/world/` — процедурный генератор (`LevelGenerator.js`), комнаты (`Room.js`), визуальные темы (`Themes.js`), декор и пространственное размещение без наложений (`Decor.js`), мир (`World.js`), мишени (`Target.js`)
- `src/player/` — движение, прыжки, рывок, камера (`Player.js`)
- `src/weapons/` — дробовик, АК-47, ракетница, снаряды, вьюмодель
- `src/enemies/` — базовый класс врага (`Enemy.js`), менеджер волн (`EnemyManager.js`), зомби (3D-модель `zombie.glb`, стили Toon с инвертированной обводкой и PBR), мутант, робот (3D-модель призрака `ghost.glb`, анимации заклинаний и полёта, растворение при гибели)
- `src/items/` — аптечки, броня, патроны (`Pickup.js`, `PickupManager.js`)
- `src/glory/` — система добиваний оглушённых врагов (`GloryKill.js`)
- `src/effects/` — декали крови, расчленение (gibs), вспышки, частицы
- `src/ui/` — HUD, переключатели графики и стилей зомби, виньетки, миникарта, отладочное меню (F2), стили

## Отладочные клавиши и читы

Все читы включаются флагом `CONFIG.debug.cheats` в `src/config.js`. При `cheats: false` не работают ни отладочные клавиши (F2, F3, F5), ни консольный объект `window.dbg`; F4 (миникарта) остаётся обычной клавишей HUD.

| Клавиша | Действие | Условие |
|---|---|---|
| **F2** | Открыть/закрыть отладочное меню (кнопки-читы). При открытии снимается Pointer Lock, курсор освобождается, управление игроком блокируется; закрытие возвращает захват мыши | `CONFIG.debug.cheats` |
| **F3** | Панель диагностики: FPS, время кадра, свет, шейдерные программы, draw calls, треугольники, вьюмодель, стиль-метр | `CONFIG.debug.cheats` |
| **F4** | Миникарта (вкл/выкл) | всегда |
| **F5** | Новый уровень с новым сидом без перезагрузки страницы (`preventDefault`) | `CONFIG.debug.cheats` |
| **T** | Заспавнить зомби рядом с игроком (быстрый тест, оставлено с прошлых версий) | всегда |

Кнопки отладочного меню (F2), слева по центру — не перекрывают миникарту и FPS. Каждая вызывает уже существующую логику игры:

- **Новый уровень** — `Game.regenerateLevel()` (новый случайный сид)
- **+40 стиля** — `StyleMeter.addPoints(40)`
- **Сбросить стиль** — `StyleMeter.reset()`
- **Выдать расходники (по 3)** — `Game.addConsumable()` до лимита `CONFIG.effects.maxStack`
- **Окно выбора перка** — `Game.debugPerkChoice()` / `Overlays.showPerkChoice`
- **Случайный перк** — `Game.debugRandomPerk()`
- **Завершить забег** — `Game.debugFinishRun()` (итоги без сохранения рекорда)
- **Спавн: пугало / призрак / зомби / мутант** — `LevelManager.debugSpawnEnemy(type)` → `ArenaController.debugSpawn` / `EnemyManager.spawnEnemyByType`
- **Режим оружия: композер/экран** — переключатель `CONFIG.graphics.weaponInComposer` (бывшая F10)
- **Бессмертие** — включатель, продлевает существующие i-frames игрока (`player.invulnT`)

Консольный аналог (только при `CONFIG.debug.cheats`):

```js
dbg.newLevel([seed])   // новый уровень
dbg.style(40)          // +40 очков стиля
dbg.resetStyle()       // сброс стиль-метра
dbg.consumables(3)     // расходники
dbg.perkChoice()       // окно выбора перка
dbg.perk()             // случайный перк
dbg.endRun()           // завершить забег
dbg.spawn('zombie' | 'robot' | 'reaper' | 'mutant')
dbg.spawnZombie() / dbg.spawnPhantom() / dbg.spawnReaper() / dbg.spawnMutant()
dbg.weaponRender()     // композер/экран для оружия
dbg.god(true | false)  // бессмертие
dbg.menu()             // открыть/закрыть меню (F2)
dbg.help()             // список команд
```

**Переназначено относительно старых версий:** F5 возвращена к генерации нового уровня (ранее выдавала +40 стиля); читы с F6–F10 (+40 стиля, сброс стиля, выбор перка, случайный перк, завершение забега, режим рендеринга оружия) больше не висят на F-клавишах и доступны только из меню F2 / `window.dbg`.
