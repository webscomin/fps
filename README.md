# FPS: Добивания и Зомби (Three.js Shooter)

Динамичный шутер от первого лица на **Three.js** + **Vite** в ретро/комиксной стилистике.
Процедурные уровни по сиду, три типа врагов, три оружия, акробатика (двойной прыжок,
рывок, rocket jump) и система добиваний (Glory Kills).

---

## 🚀 Запуск

Требуются **Node.js 18+** и **npm**.

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| **WASD** | Передвижение |
| **Пробел** | Прыжок (повтор в воздухе — двойной) |
| **Shift** | Рывок (dash) |
| **ЛКМ** | Стрельба |
| **1 / 2 / 3** или **колесо мыши** | Дробовик / АК-47 / Ракетница |
| **E** | Добивание оглушённого врага (HP < 25%) |
| **R** | Восполнить боеприпасы / рестарт после смерти |
| **T** | Заспавнить зомби (для теста) |
| **F2** | Отладочное меню читов (только при `CONFIG.debug.cheats`) |
| **F3** | Панель диагностики (только при `CONFIG.debug.cheats`) |
| **F4** | Миникарта |
| **F5** | Новый уровень с новым сидом (только при `CONFIG.debug.cheats`) |
| **Esc** | Пауза / выход из захвата мыши |

## 🧠 Принципы

- Один класс = один файл, dependency injection через `Game`.
- Все числовые параметры — в `config.js` (хардкод в HUD/эффектах устранён).
- Сид уровня воспроизводим через `Rng` (mulberry32); игровые события используют `Math.random()`.
- Оружие и эффекты используют пулы объектов; комнаты отсекаются по сетке.
- Звук синтезируется на лету, без внешних аудиофайлов; `AudioContext` создаётся после первого клика.
- В консоли доступна проверка генератора: `testLevels(50)`.

---

## 📌 Известные ограничения

- `ScreenEffects` остаётся заглушкой под будущий EffectComposer (виньетки сделаны на CSS).
- Внутренние пост-эффекты `setDrunk` / `setWeed` пока не используются игровой логикой.
- Портал в комнате `exit` активируется только после зачистки волны и переносит на новый уровень.
- Спавн волновых врагов происходит в стартовой комнате.
